# Chezmoi

My dotfiles are managed and synced using [chezmoi](https://www.chezmoi.io/)

## Apply my dotfiles to a new system:
```bash
  chezmoi init --apply theodotdot
```

## Add all modified tracked files:
```bash
  chezmoi re-add
```
