# Interesting keyboards

[Ergonaut One](https://ergonautkb.com/docs/keyboards/ergonaut-one/intro/)
Split, 42 keys, inspired by Corne and Dao, uses Xiao BLE and Gateron Low Profile switches

[Flake](https://github.com/anywhy-io/flake)
Split, 42 or 40 keys, inspired by Sofle, uses nice!nanos and can use Choc switches or MX

[Allium58](https://github.com/beekeeb/allium58)
Split, 58 keys, inspired by Lily58, uses nice!nanos and can be built for MX, chocs, or GLP switches.
Can be bought [here](https://github.com/beekeeb/allium58).

# Resources

## Layouts

[Miryoky](https://github.com/manna-harbour/miryoku) layout for inspiration on how to optimise a 36 keyboard.

[Lafayette](https://qwerty-lafayette.org/) layout is a qwerty-based layout (only 3 key difference) built to improve on the qwerty layout to write code, English and French.

[Ergo-L](https://ergol.org/) layout is a completely new layout built mainly for minimal hand movement and confort when writing code, English and French.
Additionally, see [this](https://ergol.org/claviers/compacts/#kbd_3x6) for ideas on how to optimise a 40-ish keyboard for Ergo-L.
